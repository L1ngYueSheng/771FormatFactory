# 771 Format Factory（独立版）

从 **柒柒壹工具箱** 里单独拆出来的格式转换工具：**只有一个 exe，双击即用**，不依赖工具箱、也不用安装任何东西。

文档 / 图片 / 音视频 / 数据配置 四类格式互转，另可读加密音乐文件（网易云 .ncm、酷狗 .kgm/.kgma/.vpr、QQ .qmc*/.mflac/.mgg），
还有 PDF 合并拆分提取 / **页整理（旋转 / 删除 / 重排）与元数据** + **PDF 加密 / 解密 / 加水印**、图片批量压缩 / 改尺寸 / 加水印，
以及**音视频加工**（提取音频 / 转换容器 / 按体积压缩 / 裁剪时间段 / 拼接多段）。
注:该软件为100%AI

当前版本：**v1.11**（2026-10-16）· Windows 10 / 11（64 位）

**从 v1.7 起带联网自动更新**：启动后后台查一次新版本（失败静默），有新版才弹窗问你要不要更新，
下载后自动校验（Ed25519 签名 + SHA-256）再替换并重启。也可以手动到 Releases 下载。

> 2026-10-09 起本工具与仓库名对齐：原「柒柒壹格式转换工具」→ **771 Format Factory**，exe 文件名 `771FormatFactory.exe`。

## 能转什么

- **文档**：docx / pdf / txt / md / html 等互转（docx、pypdf、reportlab）。
- **图片**：jpg / png / webp / bmp / tiff / gif / ico / avif 等互转；另有「图片工具」页做批量压缩（按质量或目标体积上限）、改尺寸、加水印。
- **音视频**：内置 ffmpeg（essentials 构建）负责转码与音轨提取（mp3 / mp2 / aac / wav / flac 等目标）。
- **数据配置**：json / yaml / csv / xlsx 等互转。
- **加密音乐解密**：网易云 .ncm、酷狗 .kgm/.kgma/.vpr、QQ 音乐 .qmc*/.mflac/.mgg（自带密钥的版本），**只在本地解密**。
- **PDF 工具**（增强页，v1.9 起是子标签页）：合并、按页拆分、提取指定页；**页整理与元数据**（整页旋转 / 删除页 / 按新页序重排；批量设标题 / 作者 / 主题）；**加密与解密**（AES-256 / AES-128 / RC4-128 / RC4-40，可另设属主密码；也能去掉别人用 Acrobat / Word / qpdf 加密的 PDF 的密码）；**加水印**（文字带中文字体、九宫位置 / 不透明度 / 字号 / 旋转 / 颜色，或图片水印）。
- **图片工具**（增强页）：批量压缩、改尺寸、文字/图片水印；另有**旋转/翻转**（左右转 90°、180°、水平/垂直翻转、任意角度，以及「按 EXIF 摆正」把手机照片的方向标记落进像素）、**边框/圆角**、**图片转 PDF**（多图按顺序合成一个 PDF，可选 A4/A3/Letter 纸型与四周白边）。
- **音视频转换页**（增强页）：对一个音视频做加工 —— 提取音频（单独存出音轨）／转换容器（mp4/mkv/webm/mov/avi）／
  按体积压缩（给目标上限如「20 MB 以内」，按原片时长反推码率、压完再核对大小）／裁剪时间段／拼接多段／
  **视频→GIF**（可截段，全片 ≤60 秒）／**抽帧（可选 4×4 九宫格缩略图）**／**提取封面**。
- 支持把文件**直接拖进窗口**；转换日志在窗口下方，出问题能看到具体原因。

> 除了「查更新」那一处（只读 GitHub Releases 的清单，失败静默），本程序**不联网**。

## 最近几版

- **v1.11** 音视频加工加**视频→GIF**（可截起止段、设帧率与宽度）、**抽帧**（每 N 秒一帧，可拼 4×4 九宫格缩略图）与**提取封面**；PDF 工具加**页整理**（整页旋转 / 删除页 / 重排）与**元数据**（标题 / 作者 / 主题）。
- **v1.10** 图片工具加三件事：**图片转 PDF**（多图按序成册、可选纸型与白边）、**旋转/翻转（含按 EXIF 摆正）**、**边框/圆角**——零新依赖。
- **v1.9** 加 **PDF 加密 / 解密**（AES-256 / AES-128 / RC4，两个方向都能做）与 **PDF 加水印**（文字/图片，落在每一页）；PDF 页改成子标签页。体积 68.4 → 约 72 MB（AES 要带密码库 cryptography）。
- **v1.8** 加**音视频转换页**（提取音频 / 转换容器 / 按体积压缩 / 裁剪时间段 / 拼接多段）。
- **v1.7** 加**联网自动更新**（与工具箱、截图工具同一套：Ed25519 验签清单 + SHA-256 校验 + 助手替换重启）；与仓库名对齐改名 771 Format Factory。
- **v1.6** 与主程序同源：接线 转换增强.py（PDF 工具 / 图片工具两页）。
- **v1.5** 与工具箱 v1.10 同源：阶段二转换类四项（PDF / 图片 / 正则改名 / 拖拽解压 + 加密压缩）。
